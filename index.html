Flagship

Basivo Orch

Draw a pipeline on a canvas and it runs without you. What comes out the other end is a thing, not a log line.

  • Issue to pull request. A GitHub issue or Jira ticket triggers an agent that edits the repo, opens the PR and comments back.
  • Narrated video. An LLM writes the script, the speech node voices it, Remotion renders it, and it posts to Telegram or Discord.
  • App Builder. Describe a frontend in chat, watch it build at a real address, deploy the version you like.
  • Six triggers. Hosted chat, webhook, schedule, Telegram bot, API call, or you pressing run.

Claude Code plugins

Give Claude memory, a browser, a QA team and a design studio. Each plugin runs locally and keeps your data in repos you own.

basivo-qa testing

Tests your web app in a real browser and hands Claude a verdict it can fix from, in the same session.

View repo

basivo-operator automation

Does plain-language tasks on any website inside your own logged-in browser. Draft-first, with a confirmation before anything irreversible.

View repo

basivo-journal productivity

Saves every session to your private GitHub repo, with secrets masked. Search past work and view a dashboard of hours, projects and tools.

View repo

basivo-memory memory

Shared memory across related repos. Pinned rules, decisions, docs and past chats from every repo in one space.

View repo

basivo-studio design

Logos, icons, covers and social images designed in SVG and HTML, then rendered to exact-size PNGs. Text is always spelled right.

Animated promo videos of your web, mobile and desktop apps, with local voiceover and generated music.
